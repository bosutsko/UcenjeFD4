POVIJEST HTML-a

OD JEDNOSTAVNOG TEKSTA DO MODERNOG WEBA

Sve je počelo 1989. godine u CERNu. Tim Berners-Lee je osmislio sustav koji bi istraivačima omogućio dijeljenje dokumenata. Taj sustav postao je poznat kao World Wide Web.

Otac weba: Sir Tim Berners-Lee

Jezik koji je definirao strukturu dokumenata nazvan je HTML (HyperText Markup Language). Njegova osnovna svrha bila je semantički opisati strukturu dokumenta, a ne njegov izgled,

Ključne verzije

  1. HTML 1.0 (1991)

    Prva neslužbena verzija.

  2. HTML 2.0 (1995)

    Prvi službeni standard.

  3. HTML 3.2 (1997)

    Uvedene tablice i apleti.

  4. HTML 4.01 (1999)

    Odvajanje CSS-a od sadržaja.

  5. HTML5 (2014)

    Video, audio i semantički elementi.

Struktura dokumenta

Osnovna struktura dokumenta izgleda ovako: 


            <!DOCTYPE html>
<html lang="hr">

<head>
    <title>Naslov stranice</title>
</head>

<body>
    <p>Pozdrav svijete!</p>
</body>

</html>

Važni pojmovi

HTTP Hypertext Transfer Protocol - protokol za prijenos podataka

URI Uniform Resource Identifier - adresa resursa na webu.

Filozofija Weba

Snaga Weba je u njegovoj univerzalnosti. Pristup svima, bez obzira na invaliditet, ključni je aspekt. -Tim Berners-Lee

Danas HTML koristimo zajedno s CSS-om i JavaScriptom. Japanski naziv za Web: 網 (Mreža)
